# Project Management Learning Hub - Site Overview

## Purpose
An accessible, interactive static website designed for SEN (Special Educational Needs) students to learn BTEC Diploma Unit 3: Project Management and Planning.

## Site Statistics
- **Total Pages**: 15 HTML pages
- **Total Lines of Code**: 3,106 lines
- **CSS**: 1 file (accessible styling)
- **JavaScript**: 3 files (interactive features)
- **No Dependencies**: Pure HTML/CSS/JS

## Site Map

### 1. Homepage (`index.html`)
- Welcome and introduction
- Four main sections: Concepts, Activities, Resources, Assessment
- Clear navigation to all areas

### 2. Concepts Section (4 pages)
- `what-is-pm.html` - Introduction to project management with cake baking analogy
- `why-planning.html` - Benefits of planning with house building example
- `project-roles.html` - Different team roles (PM, Sponsor, Team Members, Stakeholders)
- `planning-tools.html` - Overview of Gantt charts, mind maps, task lists, etc.

### 3. Activities Section (3 interactive pages)
- `project-brief.html` - Form-based activity to create a project brief
- `assign-roles.html` - Drag-and-drop activity matching people to roles
- `gantt-chart.html` - Drag-and-drop timeline creation

### 4. Resources Section
- `glossary.html` - 20 key project management terms with simple definitions

### 5. Assessment Section (2 pages)
- `quiz.html` - 10 multiple-choice questions with instant feedback
- `reflection.html` - 7 reflection questions and self-assessment checklist

## How Students Use the Site

1. **Start** → Homepage introduces the site
2. **Learn** → Read through 4 concept pages
3. **Practice** → Complete 3 interactive activities
4. **Reference** → Use glossary when needed
5. **Test** → Take the 10-question quiz
6. **Reflect** → Complete reflection activity
7. **Review** → Revisit any section as needed
